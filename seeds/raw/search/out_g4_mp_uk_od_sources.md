## Odisha (143 LGD bodies)
1. **rtiodisha.gov.in proactive-disclosure manuals** (HUD department, Departments/13).
   URL form: `https://rtiodisha.gov.in/Pages/printAllManual/office_id:<id>/lang:`. Section 4(1)(b)(ix) gives EO/Commissioner, staff and (often) councillors with mobiles and emails.
   111 bodies mapped (112 office ids). Some manuals have few phones (Bhubaneswar 176, Patnagarh 278, Khariar 297, Padampur 737, Malkangiri 838, Jajpur 1944, Balimela 4231, Nabarangpur 2773, Phulabani 3471, Rairangpur 840, Vyasanagar 814). Manual dates are not known.
   The site does not answer from Germany; use an Indian IP.
2. **SUJOG portal** (state WordPress sites per ULB): `https://sujogportal.odisha.gov.in/<slug>/`, page `/phone-directory/` = office phone + email only. 116 bodies have a slug (list in g4work/sj_res.txt). Several pages carry injected spam links (site compromise).
3. **urban.odisha.gov.in/attached-offices** (3 pages): official list of ULB own websites (51 ULBs); several are non-gov domains (<town>municipality.in, <town>nac.in).
4. Own sites found by name pattern (<town>municipality.in / <town>nac.in), checked 200 with the ULB name in the title.

## Madhya Pradesh (413 LGD bodies)
1. **District NIC (S3WaaS) directories**: `https://<district>.nic.in/en/public-utility-category/municipality/` (+ `page/2/`). Each entry = CMO office address, email (cmo<town>@mpurban.gov.in), sometimes phone. 250 bodies mapped. No page found for Ashoknagar, Mauganj, Narmadapuram, Niwari, Pandhurna, Satna, Shahdol, Tikamgarh; Umaria uses slug `urban-local-body`.
2. **mpurban.gov.in phone/email directory PDF** (no names): fallback for the other 163 bodies.
3. Own sites found by name pattern (nagarpalika<town>.*, nagarparishad<town>.*, np<town>.*): ~100 bodies; many NP sites share a vendor template (.co.in). Spam/parked domains rejected (list in g4work/mp_classify.txt).
4. mpenagarpalika.gov.in did not answer from India.
